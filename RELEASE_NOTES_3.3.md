# ADWIO Professional 3.3

UI/UX rebuild focused on compact density and functional controls.

- Compact Home, Login, Live, Movies, Series, Details, Settings and Profile.
- No repeated top navigation tabs inside content sections.
- ALL category shows total item count.
- Movies/Series start with Recently Added (30).
- Live starts in Quran category when available, otherwise the first real category instead of ALL.
- EPG removed from channel browsing UI.
- Live fullscreen channel browser reduced to a narrow side overlay so video stays visible.
- Modern player icons and functional video-quality, audio-track, subtitle-track and zoom controls.
- Live remains non-seekable/non-pausable.
- Movie/Series detail pages request real Xtream metadata when provided by the server.
- Subscription expiry epoch is formatted as a readable date.
- Focus styling no longer scales cards; it uses a compact border treatment.

Version: 3.3.0 (versionCode 9)
