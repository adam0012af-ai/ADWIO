# ADWIO Professional 4.0.0

Core reliability release.

- Content loading is now the primary startup requirement.
- Xtream network timeouts increased for large providers and API calls retry automatically.
- M3U login now validates that real playable entries exist before saving/opening the user.
- Library screens expose loading/failure states instead of remaining blank.
- User information is now a read-only information screen; host/server domains are never shown there.
- User information includes display name, username, status, source type, expiry, creation date and connection counts when provided.
- Add User screen redesigned around the approved ADWIO identity.
- Added users show customer/display name + username only.
- Normal tap switches user; long press opens Edit/Delete. Edit screen saves changes.
- About screen is fixed to one landscape screen with no scrolling.
- Settings remains fixed 4x3 with no scrolling.
- Application ID remains com.adwio.player.
- No subscription sales or content provisioning features.
