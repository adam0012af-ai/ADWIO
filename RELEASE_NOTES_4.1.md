# ADWIO Professional 4.1.0

Performance/content hotfix.

- Removed all channel/movie/series totals from Home cards.
- Totals now appear only inside the ALL category, e.g. ALL (8,918).
- M3U login uses a fast probe and never waits for the complete playlist.
- M3U library loads a fast first batch so content can appear quickly.
- Complete M3U cache warms in the background after login/library entry.
- Home no longer downloads M3U content just to calculate card totals.
- Add User screen was rebalanced to avoid the large empty layout.
- Existing saved-user tap / long-press edit-delete behavior remains.
- Xtream continues opening Recent content instead of ALL.
- Application ID remains com.adwio.player.
