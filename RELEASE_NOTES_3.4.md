# ADWIO 3.4 UI Rebuild

- Compact no-scroll login layout for landscape phone/tablet/TV.
- Home cards rebuilt as dark premium cards instead of oversized purple blocks.
- Library density increased: thinner category rail, shorter channel rows, denser poster grid.
- `ALL` carries item count; Movies/Series keep `أضيف حديثًا • 30` first.
- Live remembers the last real category; first-run fallback prefers Quran rather than ALL.
- Full-screen channel browser reduced to 38% of the screen to keep video visible.
- Player controls reduced to a thin bottom bar; Live keeps pause hidden and seek disabled.
- Settings/profile/details/playlists visually rebuilt with compact spacing.
- Version 3.4.0 (10).
