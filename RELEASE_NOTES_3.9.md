# ADWIO Professional 3.9.0

- Home no longer exposes the source host.
- Added local device clock/date using the device time zone.
- Added subscription expiry date for Xtream sessions when provided.
- Added content refresh button to the top action bar.
- Home cards now have layered visual treatment while keeping the same navigation.
- Live, Movies and Series do not open on ALL by default.
- Live starts on Recently Added; Movies and Series start on Recently Added.
- M3U parser/download timeouts were expanded for large playlists and classification was hardened.
- Settings is a fixed 4x3 grid designed to fit on one landscape screen without scrolling.
- Device/user actions remain in the top bar.
- No subscription sales or content provisioning features are included.
