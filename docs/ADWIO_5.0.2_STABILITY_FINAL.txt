ADWIO 5.0.2 Stability Final

- Cache-first Movies and Series: last successful library opens immediately.
- Failed/empty refresh no longer deletes visible saved content.
- Provider network request is no longer duplicated immediately on an empty result.
- Snapshot cache is separated by server + content type and refreshed after 30 minutes.
- M3U uses cached/partial data first and full parsing only when needed.
- Settings cards and dialogs are fully localized for Arabic/English.
- Live / Movie / Series player control bar uses a fixed LTR physical layout so language does not flip it.
- Non-applicable player buttons reserve their slots with INVISIBLE instead of collapsing the control bar.
- Version 5.0.2 / versionCode 25.
