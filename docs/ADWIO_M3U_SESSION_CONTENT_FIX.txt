ADWIO M3U SESSION + CONTENT FIX

Root causes addressed:
1. SessionStore previously required username/password keys even though M3U does not use them.
   Migrated/older M3U profiles could therefore resolve to a null Session and LibraryActivity would
   immediately finish.
2. M3U warmup and Library could issue simultaneous provider requests.
   Some providers reject/empty the second request. M3uCache is now single-flight per URL.
3. M3U active_url is now preserved/restored when switching saved M3U users.
4. Parsed full M3U content is held in memory so Live/Movies/Series reuse one loaded playlist.

Xtream path is unchanged.
