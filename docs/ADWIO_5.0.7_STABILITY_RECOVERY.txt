ADWIO 5.0.7 — Stability Recovery

Purpose:
Restore the last proven functional paths before continuing premium redesign.

Restored:
- Xtream Codes login/authentication path from the proven 4.2 implementation.
- M3U Xtream-resolver path + raw M3U fallback.
- Complete login form: name, server, username, password, M3U URL, optional EPG, Save Playlist, Connect.
- Stable PlayerActivity from 5.0.3.
- Stable LibraryActivity from 5.0.3.
- Stable Settings behavior from 5.0.3.
- Stable Android task/manifest behavior from 5.0.3.
- Premium Home retained.
- Premium Splash retained, fixed at 3 seconds, cold start routes only to Login or Home.

Intentionally removed from this recovery:
- Experimental persistent AppResumeState routing.
- Experimental launchMode/back-stack overrides.
- Experimental mandatory PiP lifecycle changes that caused black-screen regressions.
- 5.0.6 login layout regression.

Next:
Build/test this recovery first.
Only after Login + Xtream + M3U + Live + Movies + Series are confirmed stable do we re-implement PiP from one controlled playback architecture.
